01

A estrutura base de todo arquivo HTML

Todo site, simples ou complexo, começa com o mesmo esqueleto. Entender essas 6 partes já resolve 80% da confusão de quem está começando.

<!DOCTYPE html>

Primeira linha, sempre. Diz ao navegador "isso é HTML5". Sem isso, o navegador pode renderizar em "modo estranho", com CSS quebrado.

<html lang="pt-BR">

Envolve tudo. O atributo lang ajuda leitores de tela e o Google a saber o idioma — não é decoração, tem efeito real de acessibilidade e SEO.

<head>

A parte que não aparece na página. Vive aqui: título da aba, favicon, meta tags, links para CSS e o próprio <style>.

<body>

Tudo que aparece na tela. Se o head é o "escritório" da página, o body é a "vitrine".

index.html
1<!DOCTYPE html>
2<html lang="pt-BR">
3  <head>
4    <meta charset="UTF-8">
5    <title>Meu site</title>
6    <!-- CSS entra aqui dentro do head -->
7    <style> body { margin: 0; } </style>
8  </head>
9  <body>
10    <h1>Olá, mundo</h1>
11  </body>
12</html>

Esse é o esqueleto mínimo de qualquer site. Todo exemplo abaixo parte exatamente daqui.

head-completo.html
<head>
  <!-- Codificação de caracteres: sem isso, acentos quebram -->
  <meta charset="UTF-8">

  <!-- Faz o site respeitar a largura do celular (essencial!) -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Título que aparece na aba do navegador -->
  <title>Minha Loja Online</title>

  <!-- Descrição que aparece no Google -->
  <meta name="description" content="Loja de roupas com entrega rápida">

  <!-- Ícone da aba (favicon) -->
  <link rel="icon" href="favicon.png">

  <!-- CSS de um arquivo separado -->
  <link rel="stylesheet" href="estilo.css">

  <!-- OU CSS direto aqui dentro (mais rápido pra testar) -->
  <style>
    body { font-family: sans-serif; margin: 0; }
  </style>
</head>

Regra prática: CSS pequeno (uma página só) → dentro de <style> no head. CSS grande (site com várias páginas) → arquivo .css separado com <link>.

02

Sistema de modo escuro (o que você está usando agora)

Três peças: variáveis CSS pra cor, um atributo no HTML que troca o tema, e JavaScript pra alternar e lembrar a escolha. Esse site inteiro usa exatamente esse sistema — clique no botão lá em cima pra ver.

tema.css
:root {
  --bg: #fafaf9;
  --text: #1c1c1c;
  --accent: #2563eb;
}

/* Quando o HTML tiver data-theme="dark", troca os valores */
[data-theme="dark"] {
  --bg: #14161a;
  --text: #e8e6e1;
  --accent: #6ea8fe;
}

body {
  background: var(--bg);
  color: var(--text);
}
tema.js
const btn = document.getElementById('theme-toggle');
const root = document.documentElement;

// Ao carregar a página, recupera o tema salvo (ou usa o do sistema)
const salvo = localStorage.getItem('tema');
const prefereEscuro = window.matchMedia('(prefers-color-scheme: dark)').matches;
if (salvo === 'dark' || (!salvo && prefereEscuro)) {
  root.setAttribute('data-theme', 'dark');
}

btn.addEventListener('click', () => {
  const escuroAtivo = root.getAttribute('data-theme') === 'dark';
  if (escuroAtivo) {
    root.removeAttribute('data-theme');
    localStorage.setItem('tema', 'light');
  } else {
    root.setAttribute('data-theme', 'dark');
    localStorage.setItem('tema', 'dark');
  }
});

Copie essas três partes pra qualquer site e você já tem modo escuro funcionando de verdade, com a escolha salva mesmo se o usuário fechar o navegador.

04

Usando IA pra programar mais rápido

IA não substitui entender o código — mas acelera escrever, corrigir erros e aprender. Ajuste os prompts abaixo pro seu projeto real.

ChatGPT

abrir chat.openai.com ↗

Bom pra explicações passo a passo e código já formatado em blocos.

"Crie o HTML e CSS de uma landing page para [seu negócio], com modo escuro, seção hero, 3 cards de serviço e um formulário de contato. Explique cada parte do código."
"Aqui está meu código HTML: [colar código]. Está com um erro de layout no celular. Corrija e explique o que estava errado."
"Explique linha por linha o que esse CSS faz: [colar CSS]"

Grok

abrir grok.com ↗

Boa opção integrada ao X, útil pra iterar rápido em variações de design.

"Gere 3 variações de paleta de cores em CSS (--bg, --text, --accent) para um site de [tipo de negócio], modo claro e escuro para cada uma."
"Transforme este HTML estático em responsivo com CSS Grid, mantendo a mesma estrutura: [colar código]"
"Liste erros de acessibilidade neste HTML e como corrigir: [colar código]"

Dica prática: sempre cole o código real (não descreva de memória) e diga o comportamento exato esperado. Prompts vagos geram respostas vagas.
